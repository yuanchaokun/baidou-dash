How it works

三步，不用碰键盘

把"想记录"和"真的录下来"之间的所有琐事都自动化掉，你只需要坐下来、开口说。

01

写好几个问题

「今天过得怎么样？」「最有感触的一件事？」——设置一次就好。开录后它们逐个出现在画面上，也可以让系统读出来。

02

对着镜头回答

说完一题就说 回答完了，自动进下一题；说 结束录制 收尾。填一个国内模型的 Key，AI 还会根据你的回答追问一两句。

03

录完就是成片

沉默自动剪掉，问题烙成字幕，开头是带日期的封面卡。原画、分享版、封面图、文字稿四个文件按日期和标题命名，直接写进你选的文件夹。

问

竖版 3:4 取景，问题带序号出现在画面下方。语音触发词换题，或者点画面 / 按空格。

剪

沉默自动剪掉

开录前自动校准环境噪音。原画完整保留，另出一份剪掉停顿的分享版，体积小，直接发群。

封

字幕、片头、封面图

分享版自带问题字幕和 2 秒日期封面卡，发到群里缩略图就是它；另生成一张 1080×1440 的封面图。

存

直接存进你的文件夹

选一次文件夹，每次录完自动写入，不用点下载。文件名自动带日期和标题。

FAQ

常见问题

需要什么浏览器？

电脑上的 Chrome 或 Edge 最完整：滤镜录进视频、自动写入文件夹都依赖它们。Safari 可以录，但要手动「另存为」。

手机上能用吗？

可以打开录制，但这个工具是按电脑桌面设计的——大屏取景、右侧看实时转写更舒服。手机版之后再说。

语音识别和 AI 追问要花多少钱？

推荐阿里云百炼：qwen3-asr-flash 识别按音频时长计费，qwen-plus 追问按 token 计费。一天录几分钟，一个月几毛到几块钱。

我的数据存在哪里？

视频写进你选的文件夹；浏览器里另存一份用于日历回看（清理站点数据会丢，文件夹里的不会）。设置和 Key 存在本机 localStorage。

不想要字幕和片头怎么办？

设置 → 字幕与封面里可以关掉，或者只烙进分享版、保持原画干净（这是默认）。

「回答完了」识别不到？

先在设置里点「测试连接」确认接口通了；环境嘈杂时把阈值调高一点。识别不可用时，点画面或按空格也能换题。
